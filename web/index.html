模型管理

勾选哪些模型，任务池里就有哪些执行者：复合任务会被拆成按能力类型分层的小步骤 （检索 / 分析 / 编码 / 写作…），每一步交给勾选模型中该维度最强的那个。 本地模型勾选即用；进入本页时对付费模型自动实测一次连接，测不通的无法勾选。 「自动配置」仍可一键选出覆盖最全的组合；「移除」付费模型会删掉密钥配置， 移除本地模型会把它从 Ollama 里真正删除（磁盘文件一并移除）。

技能工具

两个条目集。技能：Agent Skills 开放标准，一份带 frontmatter 的 SKILL.md， 任务命中触发词时正文自动注入上下文；来源以「安装得到」为主—— 把含 SKILL.md 的目录放进技能目录即可（收尾自动提炼当前已停用）， 每张卡片展示版本、触发边界与附带资源。 工具：模型可调用的全部工具，含运行时热加载的插件工具；标「需审批」的在 默认权限下执行前会请求确认，切到「完全访问权限」后直接执行。

评测台

评测集（evals/tasks.yaml）是 harness 的标尺：每条任务喂给完整 agent 管线，判定全部走程序、零 LLM 调用——原文包含 → 归一包含 → 数值 → 关键词组 → 禁止内容 → 真跑命令核验，第一个失败的层就是失败归因（拆错了、答错了、产物坏了由此区分）。 每轮评测自动生成报告：时间、代码版本、模型、逐条表现与归因分布，用于持续优化 harness。 一轮全量评测要跑几分钟到更久（每条任务都是一次真实任务执行），期间可以切到别的栏目。
