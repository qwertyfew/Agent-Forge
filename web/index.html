我们该做什么？

越出工作区的路径与黑名单命令仍会被拦截；在「完全访问权限」下写文件与命令直接执行，切到「默认权限」则需要人工确认

可用模型管理

勾选要参与任务的模型，AgentForge 会把每个子任务分给该维度得分最高的那个。本地模型自动进入列表，付费模型填好厂商与 API Key 即可使用。

添加付费模型

填入厂商与 API Key 后，该模型立即成为「可用模型」并参与评分、路由与任务分配。密钥保存在本机 models.json（已加入 .gitignore）。

中转站或私有部署填这里，需为 OpenAI 兼容接口

Skill 管理

已安装的技能（Agent Skills 开放标准）。任务命中技能描述时，正文会自动注入本轮上下文；也可以让模型主动用 use_skill 加载。

工具管理

模型可调用的全部工具，含运行时热加载的插件工具。标「需审批」的在默认权限下执行前会请求确认；切到「完全访问权限」后直接执行。

这里存放任务跑出来的长期记忆：你在对话里明说「记住 / 以后 / 每次都…」的内容由规则直接收录； 任务收尾时还会用最便宜的本地模型再提炼一两条结论。 记忆会注入后续任务的系统提示，直接改变 Agent 的行为，所以只留结论、不留过程。
