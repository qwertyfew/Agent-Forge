# internals —— 架构关键细节存档

这个文件夹记录「代码里实际是怎么做的」级别的关键细节：每次 LLM 调用的真实输入、
判定逻辑的真实实现、以及容易凭印象记错的机制（例如「意图识别到底用没用模型」）。

与 `docs/evolution.md`（按步骤记演进）互补：evolution 记「改了什么、为什么改」，
这里记「现在到底是什么样」。每篇文档都给出来源代码位置，代码改动后同步更新。
