## 硬约束（违反会直接返工）

- **PTC 常驻**：`web_search` 直连是禁用的。工具一律经 `ops_batch` 脚本里 `tools.call(...)` 调用。
- **闸门只许证伪，不许给答案**：诊断只说「犯了什么错 + 确定性依据 + 下一步往哪走」，绝不写「改成 XXX 就对了」。
- **闸门不误伤、必须可见**：误报一次模型就怀疑所有判据；`yield` 了不等于到了前端（要有事件分支）。
- **先修上游**：取数/组装/上下文没修好时，加闸门只会让判得准、材料更少。
- **评测脚本和被测系统一样需要证据**：下结论前先把事件流按 `step` 切开；它的数字是证词不是事实。
- **每次改完自证**：相关套件全绿 → 重启服务 → 连续 3 次 health=200 再派发 → **自报这是 rerunNN**。
- 不碰 `skills/`、记忆文件、工作区之外；不删 `.git` 等版本库目录；结论写进 `docs/`，不要只留在会话里。
