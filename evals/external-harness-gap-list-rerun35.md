## 按性价比排序的借鉴清单

1. **引入 Session 上下文压缩**
   - 预期收益：显著降低长对话下的 Token 消耗，提高模型推理稳定性。
   - 预估改动面：`agentforge/context.py`（新增压缩算法）。
2. **强化 TODO 任务可视化**
   - 预期收益：提升用户对复杂任务进度的感知。
   - 预估改动面：`agentforge/taskstore.py`（增加状态标记）、`webui.py`（前端展示）。
3. **增强子代理上下文隔离**
   - 预期收益：防止子代理干扰主任务流，提高复杂任务成功率。
   - 预估改动面：`agentforge/dispatcher.py`（修改 Context 传递逻辑）。
