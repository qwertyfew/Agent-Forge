- [2026-10-13 15:30 · manual · L2] 项目约定：**本机事实与外部事实共用一条判据——结论必须有来源**。本机事实的来源就是工作区本身：任务问的是「工作区里现在有什么」（列目录 / 有哪些文件 / 看现状），而全程没调过任何能读工作区的工具（`list_dir` / `read_file` / `find_files` / `search_code`…；跑过 `run_command` 也算读过），答复里却列着具体文件名 / 目录名 → 命中 `agent.local_facts_gate`。**这道比外部那道多一层修正轮**：先明确要求它 `list_dir` 看一遍再重写，复查仍然没读才附「未经核实」声明。「去读一眼」成本极低且一定做得到，系统替它做实比事后加声明有用。两个防误报否决：任务在让它**造东西**时不出手（文件是它自己起的）、任务书里**已提过**的名字不算凭空的现状。回归：`tools/test_local_facts.py`。
